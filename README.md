My Project Description:
---

In the index.html file I created an SVG to house my shapes, 2 rectangles, 3 circles, 4 lines and a polygon (in a pentagon shape). I took these shapes and positioned them to be in the shape of a stick figure person using coordinates, making a little picture with the shapes. These shapes use various sizes, positions and colors in order to make the picture more detailed. Additionally, I added some interactive function where you can click on the pentagon shape to make it change color.
